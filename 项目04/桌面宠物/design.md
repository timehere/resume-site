# 狐狸电脑宠物 v3 设计稿

## 1. 核心定位

名字：栗栗

一句话设定：一只住在电脑桌面边缘的小狐狸，会陪你学习、工作和休息，并能在 3D 软萌风与 2D RPG 像素风之间切换。

关键词：狐狸、桌面陪伴、低打扰、可拖拽、休息提醒、3D/像素双形态。

## 2. 视觉风格

### A. 3D 风：参考图真实毛发狐狸

外观：
- 直接参考用户提供的狐狸图：橘棕毛发、白色胸口、白色尾尖、黑色小腿。
- 站立姿态，头部略偏向用户，眼睛有高光。
- 大尾巴在身体左侧向下垂，尾尖是奶油白。
- 动画以整体呼吸、弹跳、趴下压扁、拖拽晃动为主。
- 摸头和睡觉用覆盖层表现眯眼，打哈欠用覆盖层表现圆嘴。

用途：
- 日常陪伴。
- 鼠标靠近、摸头、拖拽等细腻互动。
- 休息提醒和晚安提示。

### B. 2D RPG 像素风：像素狐狸伙伴

外观：
- 低分辨率块状狐狸精灵。
- 保留参考图的站立姿势、大尾巴、白胸口、白尾尖和深色小腿。
- 动画用 2-3 帧模拟上下跳、走路、趴下和眯眼。

用途：
- RPG 风界面。
- 低性能模式。
- 之后接入游戏或桌面小组件。

## 3. 风格切换

切换规则：
- 3D 和 2D 是同一只狐狸的两套外观。
- 切换时保留当前动作和台词。
- 用户可通过顶部 `3D / 2D RPG` 按钮手动切换。

## 4. 动作与互动

主要动作：
- 走路：左右移动，腿部交替。
- 趴下：身体压低变扁。
- 睡觉：趴下并出现 `Z`。
- 打哈欠：嘴巴变圆。
- 跳一下：向上弹跳再落地。
- 摸头眯眼：鼠标靠近头顶区域时触发。
- 长时间不操作：偷偷打盹并提醒休息。

互动方式：
- 鼠标靠近：抬头看鼠标。
- 点击它：随机说一句话，并跳一下。
- 拖拽它：被拎起来，松手后晃一下。
- 长时间学习/工作：提醒你休息。
- 到晚上：自动说晚安。

已实现：

- 两种风格切换。
