Lili Desktop Pet for Windows

How to run:

1. Extract the whole zip file first.
   Do not run the app directly inside the zip preview window.

2. Open the extracted folder.

3. Double-click:
   start-lili-desktop-pet.bat

4. If Windows SmartScreen blocks it:
   Click "More info" -> "Run anyway".

5. If it still does not show:
   Right-click start-lili-desktop-pet.bat and choose "Run as administrator".

6. If it still fails:
   Send back the two log files on the Desktop:
   - lili-desktop-pet-start.log
   - lili-desktop-pet-error.log

Important:

- Do not send or run only the exe file.
- Keep the whole extracted folder together.
- The dll files, resources folder, and locales folder are required.
